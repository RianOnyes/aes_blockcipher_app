🔐 Aplikasi Kriptografi AES (Advanced Encryption Standard)
🧩 Deskripsi

Aplikasi ini merupakan simulasi enkripsi dan dekripsi teks menggunakan algoritma AES (Advanced Encryption Standard) berbasis PHP + OpenSSL.
Pengguna dapat memilih mode enkripsi AES-128-CBC atau AES-256-CBC.
Kunci rahasia diolah secara otomatis agar sesuai dengan panjang kunci yang dibutuhkan oleh masing-masing mode.

⚙️ Fitur Utama

Enkripsi teks menjadi ciphertext menggunakan AES-CBC.

Dekripsi ciphertext kembali ke teks asli.

Dukungan dua panjang kunci: 128-bit dan 256-bit.

IV (Initialization Vector) dihasilkan secara acak setiap proses enkripsi.

Hasil enkripsi dikodekan dalam Base64 agar mudah disalin dan ditempel.

Tampilan menggunakan Bootstrap 5 dengan desain sederhana dan responsif.
